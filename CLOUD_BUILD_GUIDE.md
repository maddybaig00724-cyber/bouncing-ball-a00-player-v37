# Cloud build guide

1. Create/open a GitHub repository.
2. Upload the CONTENTS of this folder, not this ZIP.
3. Keep `.github/workflows/build-apk.yml` in exactly that path.
4. Confirm `app/` is at repository root.
5. Commit the files to `main`.
6. Open the repository's Actions tab.
7. Open `Build Bouncing Ball A00 Player APK`.
8. Run it with `Run workflow` if it did not start automatically.
9. When successful, open the workflow run and download the artifact named `BOUNCING-BALL-A00-PLAYER-V36-APK`.

If the workflow fails, send the failed step/log screenshot before changing files.
